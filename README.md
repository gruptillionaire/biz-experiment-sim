# biz-experiment-sim
Simulating outcomes for business experiments

Lightweight product-metric sim for modelling effects of an experiment affecting acquisition, retention, conversion, revenue and cost metrics.

## Purpose

This project explores how product & business experiments can be compared through simple deterministic modelling. It is designed as an internal decision tool rather than a prediction engine

## Planned MVP

Baseline metrics input
Experiments input
12-mon simulation
Baseline vs experiment comparison
Revenue, profit, CAC spend, active users, payback outputs

## Stack

React + TSX // frontend
Python // backend
Rechart // charts
FastAPI // POST methods
Pydantic // strict backend->frontend typechecking for POST
vite // local web app hosting
